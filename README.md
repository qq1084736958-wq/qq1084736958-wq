## 📌 我的工作方式

- **先定义边界**：Agent 不追求"全自主"，而是固定、可控的编排——可测试、可解释、可追溯
- **审核与修正闭环**：生成不是终点，风险修正 + 复审 + 人工确认才是交付
- **服务端优先**：Token 安全、任务持久化、失败恢复，而不是把凭据暴露给浏览器
- **测试驱动**：输入校验、红线审核、结果解析全部有自动化测试覆盖
